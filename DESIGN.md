# Arctos Launchpad Design System

## Creative concept

The homepage is an art-book field guide to one connected growth system. It opens as a dark technical cover, moves through four full-viewport chapters, changes medium for the operational explanation and work, and ends on a deliberately lighter studio note.

Every major scene needs its own composition. Repeating the same heading/card/grid pattern is a design failure, even when the colors change.

## Design dials

- Design variance: 9
- Motion intensity: 6
- Visual density: 5

## Brand thread

- Arctic ink: `#08151c`
- Field paper: `#eee9de`
- Signal blue: `#66b6ff`
- Attract: cobalt `#1769bd`
- Convert: burgundy `#8d2c46`
- Operate: burnt orange `#c9580d`
- Scale: forest `#2b7768`

The chrome color is not fixed. Header, navigation marks, and chapter dots inherit the active chapter ink and accent so the interface stays legible as artwork changes.

## Type

The main UI and commercial statements use a strong system grotesk. An italic old-style serif is reserved for chapter voices, emotional turns, and taped notes. The contrast should feel editorial and human, not luxury-fashion ornamental.

## Texture and image use

Paper grain and turbulence overlays are quiet material cues, never foreground effects. Chapter art is full-bleed and owns the viewport. Real project captures appear without fake browser chrome. The bear is a closing signature, not a hero or outdoor-brand motif.

## Motion

The chapter story uses one sticky stage and crossfades composited image/text layers. Scroll progress also changes the site chrome palette. Entrances use short transform/opacity motion; interaction feedback stays under 300ms. Reduced motion converts the chapter stack into four natural full-height sections and removes scrubbing.

## Layout

Desktop uses deliberate asymmetry, oversized type, thin rules, taped paper, and a 12-column work mosaic. Mobile preserves the visual hierarchy rather than reducing every scene to generic cards. Full-screen menu treatment is translucent enough for the current artwork to remain faintly present.
