# Brand discovery: Arctos Launchpad

The supplied search conversation repeatedly confused the company with investment,
aerospace and database products, then described it as a hidden deployment framework.
Those answers are feedback about recognition, not evidence about the business or
proof that the site is missing from an index.

## Site changes

Describe Arctos Launchpad plainly as a Calgary marketing and software agency.
Use the full name with that description in visible homepage and About copy,
the footer, metadata, organization structured data and the existing `/llms.txt`.
The About page identifies the same organization node used across the site.
Keep the bridge narrative, real portfolio evidence and service links alongside
that factual introduction. Do not add unrelated companies to the site or invent
partnerships to rebut generated answers.

## After deployment

- Verify the live homepage and About page contain the updated copy and metadata.
- In Google Search Console and Bing Webmaster Tools, check the canonical domain,
  sitemap processing and indexing status; request reindexing of the changed pages.
- Use the exact name **Arctos Launchpad**, the canonical website URL and the same
  agency description on company profiles the owner controls. Add profile URLs to
  structured data only after verifying they represent this company.
- Where appropriate, link client credits to the canonical company website using
  the full brand name. Do not treat footer credits as a substitute for an About page.
- Monitor branded queries and referrals after recrawling. Record the engine,
  query and date when an answer misidentifies the company.

`/llms.txt` is a supplementary summary; support varies by crawler. Clear public
pages, consistent identity and indexing are the primary signals. These changes
cannot guarantee rankings, citations or immediate corrections to generated answers.
